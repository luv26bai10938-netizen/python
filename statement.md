Project Statement

Project: Python Scientific Calculator (VITyarthi – Build Your Own Project)  
Author: Luv Vikrant Saxena (26BAI10938)

1. Problem

Many students want results fast, but basic arithmetic is not enough. They often need values like trigonometric results, powers, and square roots. A real scientific calculator is not always nearby. Also, common app stores bring tools that look messy, or they ask for setup time and internet.

To handle this, the project builds a small command-line Scientific Calculator using Python. A user picks an operation, types in numbers, and gets the answer right away. The program also shows common programming ideas such as input and output, if-else choices, functions, and use of the math library.

2. Project scope

In scope  
- A menu style command-line tool in Python  
- Basic arithmetic: add, subtract, multiply, divide  
- Scientific tasks: sine, cosine, cosecant, power, square root  
- Degree to radian conversion for trig functions  
- Input checks, plus error handling for wrong operators, non-numeric input, and division by zero  
- Clear code structure, with reusable parts as modules  

Out of scope  
- Any graphical or web interface  
- Symbolic algebra, graph plotting, and equation solving  
- Keeping calculation history after the app is closed  

3. Who will use it

- School and college students who need quick scientific math on a computer  
- Beginners learning Python who want a simple modular example  
- People who want fast offline calculations without installing extra software  

4. Main features

Feature, Description  
Basic arithmetic, Add, subtract, multiply and divide two numbers.  
Trigonometric functions, Sine, cosine, and cosecant for an angle
